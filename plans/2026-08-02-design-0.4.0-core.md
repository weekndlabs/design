# 0.4.0 core implementation plan

> **For Claude:** execute this with the `superpowers:executing-plans` skill, one
> task at a time, committing at the end of each.

**Goal:** land the core of the identity in
[`specs/2026-08-01-macos-identity-0.4.0-design.md`](../specs/2026-08-01-macos-identity-0.4.0-design.md):
one neutral ladder, one system blue, Inter and JetBrains Mono, the radius ladder
with continuous corners, ten terminal tokens, and the tests that hold all of it.

**Architecture:** unchanged. Style Dictionary reads `tokens/*.json`, four
formatters in `build/` emit `dist/`, and `lib/*.test.js` gates the values. This
plan changes what the tokens say, not how they are built, apart from two
formatter changes that new token shapes force.

**Tech stack:** Node 22, Style Dictionary 5, node:test, Astro 7 for the docs
site.

**Out of scope, planned separately:** archetypes, components, prose styles and
the Figma library. Phase list at the end.

## Before you start

Three facts about this repo that will cost you an hour if you learn them the
hard way.

`dist/` is committed. Twenty one files are tracked. Every task that changes a
token runs `npm run build` and commits `dist/` in the same commit as the source,
or the package on npm stops matching the repo.

`npm test` output cannot be trusted through a pipe. OMNI truncates piped and
redirected test output here. Read the exit code, not the summary line. Run
`npm test; echo "exit $?"`.

Tests already encode most of the spec. `lib/tokens.test.js` asserts foreground at
7:1 on card, muted and sidebar, muted-foreground at 4.5:1 on four surfaces,
banded surfaces at least 1.03:1 from the page, chart hues 25 degrees apart, and
warning 20 degrees from primary. Every value in this plan has been measured
against those gates already and passes. If a value fails, the value is wrong,
not the gate.

## Task 5: the chroma ceiling

The gate that stops a dark theme drifting blue while its light twin stays grey.
Nobody catches this by eye, which is the whole reason it is a test.

**Files:** modify `lib/tokens.test.js`

**Step 1: write the failing test**

```js
/** Neutral roles are the ones with no hue of their own. */
const NEUTRAL = new Set([
  'background', 'foreground', 'card', 'card-foreground',
  'popover', 'popover-foreground', 'primary', 'primary-foreground',
  'secondary', 'secondary-foreground', 'muted', 'muted-foreground',
  'accent', 'accent-foreground', 'border', 'input',
  'sidebar', 'sidebar-foreground', 'sidebar-accent', 'sidebar-accent-foreground',
  'sidebar-border',
]);

const chromaOf = (value) => Number(/^oklch\([\d.]+ ([\d.]+) /.exec(value)[1]);

test('no neutral carries a visible hue', () => {
  // Apple's greys sit around 0.004 and read as grey. Past 0.008 a theme starts
  // leaning toward a colour, and the usual failure is a dark theme going blue
  // while its light twin stays neutral. That is invisible until the two are
  // compared side by side, which nobody does.
  for (const theme of THEMES) {
    for (const role of NEUTRAL) {
      const chroma = chromaOf(themes[theme][role]);
      assert.ok(chroma <= 0.008, `${theme}.${role} chroma ${chroma}, ceiling 0.008`);
    }
  }
});
```

**Step 2: prove it can fail**

Temporarily change `neutral.850` in `tokens/color.primitive.json` to
`oklch(0.2273 0.042 264.7)`, the shadcn slate default.

Run: `npm test; echo "exit $?"`
Expected: fails with `dark.card chroma 0.042, ceiling 0.008`.

Revert the value.

**Step 3: run and commit**

Run: `npm test; echo "exit $?"` Expected: exit 0.

```bash

git commit -m "test(tokens): cap neutral chroma at 0.008"

## Task 9: container widths, and the trap that comes with them

**Files:** modify `build/format-ts.js`, `build/format-tailwind.js`, `README.md`

not work, the same way media queries cannot read custom properties. They ship as
JS only, and the README says so, because trying it is the obvious first move.

```

**Step 2: keep them out of the CSS**

`build/format-css.js` emits everything that is not a colour. Exclude
`container.*` there, and assert it in `lib/build.test.js`:

```js
test('container widths never reach the CSS', () => {
  assert.doesNotMatch(css, /--wl-container-/,

```

## Task 11: the overflow sweep

The check that would have caught both sideways scroll bugs this system has had.

375, 390, 414, 430, 480, 540, 600, 768, 860, 1024 and 1280, and fails if
