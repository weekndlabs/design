# robots.txt applies per host, and this site answers on two of them.
#
# This host is NOT the canonical one: every page here canonicalises to
# weekndlabs.com/design. It stays fully crawlable on purpose. Disallowing it
# would stop Google reading the canonical tag that does the deduplicating, which
# is the opposite of what blocking a duplicate achieves.
#
# weekndlabs.com is behind Cloudflare, which injects a managed block list for AI
# training crawlers. design.weekndlabs.com is served by Vercel directly, so none
# of that reached it and this host answered 404 to /robots.txt, which means allow
# everything. The main site's policy was not being applied here at all.
#
# This file states the same policy by hand. It will drift: Cloudflare maintains
# its list and adds agents over time, and nothing syncs the two. Compare against
# https://weekndlabs.com/robots.txt when the policy matters.

User-agent: *
Content-Signal: search=yes,ai-train=no,use=reference
Allow: /

# Training crawlers, matching the set Cloudflare blocks on weekndlabs.com.
User-agent: Amazonbot
Disallow: /

User-agent: Applebot-Extended
Disallow: /

User-agent: Bytespider
Disallow: /

User-agent: CCBot
Disallow: /

User-agent: CloudflareBrowserRenderingCrawler
Disallow: /

User-agent: Google-Extended
Disallow: /

User-agent: meta-externalagent
Disallow: /

# ClaudeBot and GPTBot are NOT blocked here, and that is deliberate rather than an
# oversight. The Content-Signal above says use=reference: being cited is wanted.
# Those two are the agents that fetch a page in order to cite it, so blocking them
# asks for the citation and refuses the fetch. The main site blocks them and its
# own signal contradicts that; this host does not repeat the contradiction.
#
# The training-only agents above stay blocked, which is what ai-train=no means.

# The canonical host is weekndlabs.com/design, so the sitemap is named there.
#
# This file only ever answers at design.weekndlabs.com/robots.txt, because
# robots.txt is read from an origin root and never from a path. Google reads
# weekndlabs.com/robots.txt for the canonical host, and that file belongs to the
# main site's repo, so this directive alone does not get the sitemap discovered.
# It has to be added there as well, or submitted in Search Console.
Sitemap: https://weekndlabs.com/design/sitemap.xml
