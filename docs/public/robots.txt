# robots.txt applies per host, and this site answers on two of them.
#
# weekndlabs.com is behind Cloudflare, which injects a managed block list for AI
# training crawlers. design.weekndlabs.com is served by Vercel directly, so none
# of that reached it and this host answered 404 to /robots.txt, which means allow
# everything. The main site's policy was not being applied here at all.
#
# This file states the same policy by hand. It will drift: Cloudflare maintains
# its list and adds agents over time, and nothing syncs the two. Compare against
# https://weekndlabs.com/robots.txt when the policy matters.
